An AI-powered practice app that trains corporate finance analysts on the real AI-era workday through puzzles: econciliation, forecasting, scenario analysis, treasury, reporting and governance.

## Features
- AI-generated puzzles across 6 workday areas and 20 responsibilities
- Python-verified calculation puzzles
- "Best next action" scenarios for AI-flagged issues
- Deep dives, key-term glossary, and a skill checklist
